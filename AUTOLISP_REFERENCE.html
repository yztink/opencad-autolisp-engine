OpenCAD Studio AutoLISP Function Reference

Complete reference manual for all built-in functions, special forms, CAD bridge operations, Visual LISP extensions, and native UI controls implemented in the opencad-lisp engine.

Argument Conventions: arg Required [arg] Optional arg1 ... Variadic (zero or more)

Special Forms & Control Flow

15 functions

setq
SYNTAX
`(setq sym1 expr1 [sym2 expr2 ...])`

Assigns the result of each expression to its preceding symbol sequentially and returns the last assigned value.

EXAMPLE 
(setq radius 25.0
      area (* pi radius radius))

set
SYNTAX
`(set sym-expr val-expr)`

Evaluates sym-expr to obtain a symbol and binds it to the evaluated val-expr.

EXAMPLE 
(setq var-name 'my-var)
(set var-name 42) ; sets my-var to 42

quote
Aliases: '
SYNTAX
`(quote expr)` or `'expr`

Returns expr unevaluated.

EXAMPLE 
(setq pts '((0 0 0) (10 10 0)))

defun
SYNTAX
`(defun name ([param1 ...] [/ local1 ...]) expr1 ...)`

Defines a function or CAD command. Prefixing name with c: (e.g., c:mycmd) automatically registers MYCMD as a top-level command in OpenCAD Studio. Symbols after / are scoped as local variables initialized to nil.

EXAMPLE 
(defun area-circle (r / a)
  (setq a (* pi r r))
  a
)
(defun c:drawbox ()
  (command "_.LINE" '(0 0) '(10 0) '(10 10) '(0 10) "C")
)

lambda
SYNTAX
`(lambda ([param1 ...] [/ local1 ...]) expr1 ...)`

Creates an anonymous function closure, commonly used with mapcar, apply, or vl-remove-if.

EXAMPLE 
(mapcar '(lambda (x) (* x 2)) '(1 2 3 4)) ; => (2 4 6 8)

if
SYNTAX
`(if test-expr then-expr [else-expr])`

Evaluates test-expr. If non-nil, evaluates and returns then-expr; otherwise evaluates and returns else-expr (or nil if omitted).

EXAMPLE 
(if (> x 0) "Positive" "Non-positive")

cond
SYNTAX
`(cond (test1 [expr1 ...]) [(test2 [expr2 ...]) ...])`

Evaluates each test clause in order until one evaluates to non-nil, then evaluates the body expressions of that clause and returns the last result.

EXAMPLE 
(cond
  ((= color "Red") 1)
  ((= color "Green") 3)
  (t 7)
)

while
SYNTAX
`(while test-expr [body-expr1 ...])`

Repeatedly evaluates the body expressions as long as test-expr evaluates to non-nil. Returns the last evaluated expression.

EXAMPLE 
(setq i 0)
(while (< i 5)
  (princ i)
  (setq i (1+ i))
)

repeat
SYNTAX
`(repeat count [body-expr1 ...])`

Evaluates the body expressions count times (where count is a non-negative integer) and returns the result of the final expression.

EXAMPLE 
(setq total 0)
(repeat 4 (setq total (+ total 10))) ; => 40

foreach
SYNTAX
`(foreach var list [body-expr1 ...])`

Iterates through every element in list, binding var to each item and evaluating the body expressions.

EXAMPLE 
(foreach pt '((0 0) (10 0) (10 10))
  (print pt)
)

progn
SYNTAX
`(progn [expr1 ...])`

Evaluates multiple expressions sequentially as a single block and returns the result of the last expression.

EXAMPLE 
(if draw-x
  (progn
    (princ "\nDrawing X...")
    (command "_.LINE" '(0 0) '(10 10) "")
  )
)

and
SYNTAX
`(and [expr1 ...])`

Logical short-circuit AND. Evaluates expressions left-to-right; stops and returns nil at the first nil expression, or T/truthy if all succeed.

EXAMPLE 
(and pt (> (car pt) 0.0))

or
SYNTAX
`(or [expr1 ...])`

Logical short-circuit OR. Evaluates expressions left-to-right and returns the first non-nil value, or nil if all are nil.

EXAMPLE 
(or (= ans "Y") (= ans "y"))

eval
SYNTAX
`(eval expr)`

Evaluates expr a second time as an AutoLISP expression.

EXAMPLE 
(setq code '(+ 10 20))
(eval code) ; => 30

boundp
SYNTAX
`(boundp sym)`

Returns T if the symbol is bound to a non-nil value in the current environment, or nil otherwise.

EXAMPLE 
(boundp 'pi) ; => T

T
Aliases: nil pi PAUSE
  • T: Boolean true constant.
  • nil: Boolean false / empty list constant.
  • pi: Mathematical constant pi (approx. 3.141592653589793).
  • PAUSE: Pause token ("\\") used in (command ...) calls for interactive user input.
EXAMPLE 
(setq circumference (* 2.0 pi 25.0))
(command "_.CIRCLE" PAUSE 25.0)

Returns version and implementation strings for the AutoLISP runtime.

Math, Bitwise & Geometry Functions

20 functions

+
SYNTAX
`(+ [num1 num2 ...])`

Returns the sum of all numbers. Returns 0 if no arguments are supplied. Promotes to Real if any argument is a float.

EXAMPLE 
(+ 10 20 5.5) ; => 35.5

-
SYNTAX
`(- [num1 num2 ...])`

With one argument, negates num1. With multiple arguments, subtracts num2 ... from num1.

EXAMPLE 
(- 50 15 5) ; => 30
(- 12)      ; => -12

*
SYNTAX
`(* [num1 num2 ...])`

Returns the product of all numbers. Returns 1 if no arguments are given.

EXAMPLE 
(* 4 5 2.0) ; => 40.0

/
SYNTAX
`(/ [num1 num2 ...])`

Divides num1 by num2 and any subsequent divisors. Integer operands perform integer division; include a float for decimal division.

EXAMPLE 
(/ 100.0 4 5) ; => 5.0

1+
Aliases: 1-
SYNTAX
`(1+ num)` / `(1- num)`

Increments (1+) or decrements (1-) num by 1.

EXAMPLE 
(1+ 9) ; => 10
(1- 9) ; => 8

abs
SYNTAX
`(abs num)`

Returns the absolute value of num.

EXAMPLE 
(abs -42.5) ; => 42.5

max
Aliases: min
SYNTAX
`(max num1 [num2 ...])` / `(min num1 [num2 ...])`

Returns the largest (max) or smallest (min) of the given numbers.

EXAMPLE 
(max 3 18 -2 7) ; => 18
(min 3 18 -2 7) ; => -2

rem
SYNTAX
`(rem num1 num2 [num3 ...])`

Divides num1 by num2 (and subsequent divisors) and returns the remainder.

EXAMPLE 
(rem 17 5) ; => 2

gcd
SYNTAX
`(gcd int1 int2)`

Returns the greatest common divisor of two integers.

EXAMPLE 
(gcd 84 36) ; => 12

sqrt
SYNTAX
`(sqrt num)`

Returns the square root of a non-negative number as a real.

EXAMPLE 
(sqrt 2.0) ; => 1.4142135623730951

expt
SYNTAX
`(expt base power)`

Raises base to the specified power.

EXAMPLE 
(expt 2 10) ; => 1024

sin
Aliases: cos
SYNTAX
`(sin ang)` / `(cos ang)`

Returns the sine or cosine of ang (specified in radians).

EXAMPLE 
(cos 0.0)        ; => 1.0
(sin (/ pi 2.0)) ; => 1.0

atan
SYNTAX
`(atan num1 [num2])`

Returns the arctangent of num1 in radians, or atan2(num1, num2) if num2 is provided.

EXAMPLE 
(atan 1.0 1.0) ; => 0.7853981633974483

log
Aliases: exp
SYNTAX
`(log num)` / `(exp num)`

log returns the natural logarithm (ln) of num. exp returns e raised to the power of num.

EXAMPLE 
(log (exp 1.0)) ; => 1.0

float
Aliases: fix
SYNTAX
`(float num)` / `(fix num)`

float converts a number to a floating-point Real. fix truncates a number toward zero to an Int.

EXAMPLE 
(float 5)  ; => 5.0
(fix 3.95) ; => 3

logand
Aliases: logior ~ lsh boole
SYNTAX
`(logand int1 int2 ...)`
`(logior int1 int2 ...)`
`(~ int)`
`(lsh int bits)`
`(boole op int1 int2 ...)`

Bitwise integer operations: AND (logand), OR (logior), bitwise NOT (~), logical bit shift (lsh), and general bitwise operator (boole, where 1=AND, 6=XOR, 7=OR, 8=NOR).

EXAMPLE 
(logand 7 3)    ; => 3
(logior 4 2)    ; => 6
(lsh 1 4)       ; => 16
(boole 6 12 10) ; => 6

distance
SYNTAX
`(distance pt1 pt2)`

Returns the 2D or 3D Euclidean distance between points pt1 and pt2.

EXAMPLE 
(distance '(0 0 0) '(3 4 0)) ; => 5.0

angle
SYNTAX
`(angle pt1 pt2)`

Returns the angle in radians in the XY plane from pt1 to pt2 measured counter-clockwise from the positive X axis.

EXAMPLE 
(angle '(0 0) '(0 10)) ; => 1.5707963267948966

polar
SYNTAX
`(polar pt ang dist)`

Returns a new 3D point displaced from pt at angle ang (in radians in the XY plane) by distance dist.

EXAMPLE 
(polar '(10.0 10.0 0.0) 0.0 25.0) ; => (35.0 10.0 0.0)

inters
SYNTAX
`(inters pt1 pt2 pt3 pt4 [onseg])`

Computes the intersection point of line (pt1, pt2) and line (pt3, pt4). If onseg is omitted or non-nil, the intersection must lie on both finite segments; if nil, the lines are treated as infinite.

EXAMPLE 
(inters '(0 0) '(10 10) '(0 10) '(10 0)) ; => (5.0 5.0 0.0)

Comparison, Logic & Type Predicates

6 functions

=
Aliases: < <= > >=
SYNTAX
`(= a b [c ...])`, `(/= a b)`, `(< a b [c ...])`, `(<= a b [c ...])`, `(> a b [c ...])`, `(>= a b [c ...])`

Compares numbers or strings. Returns T if the relation holds across arguments, or nil otherwise.

EXAMPLE 
(< 1 5 10)        ; => T
(/= "Red" "Blue") ; => T

eq
Aliases: equal
SYNTAX
`(eq expr1 expr2)` / `(equal expr1 expr2 [fuzz])`

Checks equality of two expressions. equal performs deep structural comparison and accepts an optional numeric fuzz tolerance.

EXAMPLE 
(equal 10.0001 10.0 0.001) ; => T

not
Aliases: null
SYNTAX
`(not expr)` / `(null expr)`

Returns T if expr is nil, or nil otherwise.

EXAMPLE 
(null nil) ; => T

atom
Aliases: listp vl-consp
SYNTAX
`(atom expr)` / `(listp expr)` / `(vl-consp expr)`

atom returns T if expr is not a cons cell. listp returns T for lists or nil. vl-consp returns T only for non-empty lists.

EXAMPLE 
(listp '(1 2 3)) ; => T
(vl-consp nil)   ; => nil

numberp
Aliases: minusp zerop
SYNTAX
`(numberp expr)` / `(minusp num)` / `(zerop num)`

numberp returns T if expr is an integer or real. minusp tests if num < 0. zerop tests if num == 0.

EXAMPLE 
(numberp 3.14) ; => T
(minusp -5)    ; => T
(zerop 0.0)    ; => T

type
SYNTAX
`(type expr)`

Returns a symbol representing the data type of expr (INT, REAL, STR, SYM, LIST, SUBR, USUBR, ENAME, PICKSET, VLA-OBJECT, FILE, or nil).

EXAMPLE 
(type 42)     ; => INT
(type "text") ; => STR

Constructs a pair/list by prepending first onto rest (or creating a dotted pair (a . b) when rest is an atom).

(list 10.0 20.0 0.0) ; => (10.0 20.0 0.0)

Concatenates multiple lists into a single flat list.

(append '(1 2) '(3 4)) ; => (1 2 3 4)

reverse
SYNTAX

Returns a new list with the top-level elements in reverse order.

EXAMPLE 
(reverse '(1 2 3)) ; => (3 2 1)

length
SYNTAX
`(length list)`

Returns the number of elements in list as an integer.

EXAMPLE 
(length '(a b c d)) ; => 4

nth
SYNTAX

SYNTAX

Returns the last element in list.

EXAMPLE

car
Aliases: cdr caar` .. `cddddr
SYNTAX
`(car list)`, `(cdr list)`, `(cadr list)`, `(caddr list)`, etc.

Extracts the head (car), tail (cdr), X-coordinate (car), Y-coordinate (cadr), Z-coordinate (caddr), and all combinations up to 4 levels deep (caar through cddddr).

EXAMPLE 
(setq pt '(15.0 25.0 5.0))
(car pt)   ; => 15.0
(cadr pt)  ; => 25.0
(caddr pt) ; => 5.0

assoc
SYNTAX
`(assoc key alist)`

Searches an association list alist for a pair whose car equals key and returns that pair, or nil if not found.

EXAMPLE 
(assoc 40 '((0 . "CIRCLE") (40 . 25.0))) ; => (40 . 25.0)

member
SYNTAX
`(member expr list)`

Searches list for expr and returns the sublist starting at the matching element, or nil if not found.

EXAMPLE 
(member 'b '(a b c d)) ; => (B C D)

subst
SYNTAX
`(subst new-item old-item list)`

Returns a copy of list with every occurrence of old-item replaced by new-item.

EXAMPLE 
(subst '(40 . 50.0) '(40 . 25.0) '((0 . "CIRCLE") (40 . 25.0)))

apply
SYNTAX
`(apply func arg-list)`

Invokes func (a symbol or lambda) using the elements of arg-list as its arguments.

EXAMPLE 
(apply '+ '(10 20 30)) ; => 60

mapcar
SYNTAX
`(mapcar func list1 [list2 ...])`

Applies func element-wise across one or more lists and returns a list of the results.

EXAMPLE 
(mapcar '+ '(1 2 3) '(10 20 30)) ; => (11 22 33)

entmake
Aliases: entmakex
SYNTAX
`(entmake dxf-alist)` / `(entmakex dxf-alist)`

Creates a new CAD entity ("LINE", "CIRCLE", "POINT") from a DXF group-code association list (0=type, 8=layer, 10=start/center point, 11=end point, 40=radius, 62=ACI color index). entmake returns the input list; entmakex returns the new ENAME.

               (cons 40 30.0)
               (cons 62 1))) ; ACI 1 = Red

EXAMPLE

Modifies an existing entity's properties using an updated DXF association list (entmod) and refreshes its display (entupd).

EXAMPLE 
(entmod (subst (cons 40 50.0) (assoc 40 data) data))

entdel
